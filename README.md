 1. Datei-Menü aufrufen
   Optionen bei AntiCheat.jar
   Klicke direkt neben der Datei AntiCheat.jar auf das Drei-Punkte-Symbol (⋮ oder …), um das Menü zu öffnen.
 2. Datei herunterladen
   Herunterladen der .jar-Datei
   Wähle im geöffneten Menü die Option Download aus. Die Datei wird in deinen Standard-Download-Ordner auf dem PC gespeichert.
 3. CurseForge öffnen
   Modpack-Profil ansteuern
   Starte die CurseForge-App und wähle in deiner Bibliothek das Minecraft-Modpack aus, das ihr zusammen nutzt.
 4. Mod-Ordner öffnen
   Direktzugriff über den Launcher
   Klicke im Profil des Modpacks auf die drei Punkte (neben der Schaltfläche „Spielen“) und wähle Ordner öffnen (Open Folder). Öffne dort den Unterordner mods.
 5. Mod-Datei verschieben
   Datei im Ordner platzieren
   Gehe in deinen Downloads-Ordner auf dem PC, kopiere die neu heruntergeladene AntiCheat.jar und ziehe sie direkt in den geöffneten mods-Ordner.
 6. Spiel starten
   Änderungen laden
   Starte Minecraft über CurseForge neu, damit die geänderte Mod-Liste übernommen und geladen wird.
